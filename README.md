Key Features:

Market Price Overview — View essential commodity prices in one place.

Price Comparison — Compare market prices to make informed purchasing decisions.

Price Trend Indicators — View price increase and decrease indicators for selected commodities.

User Authentication — Sign up, sign in, and manage your account with authentication.

User Profile Management — Access profile information and account options through a personalized user menu.


Technologies Used:

Next.js — React framework for building the web application.

React — Component-based user interface development.

TypeScript — Type-safe JavaScript development.

Tailwind CSS — Responsive styling and UI design.

Better Auth — User authentication and session management.

React Hot Toast — Toast notifications.

Vercel — Application deployment and hosting.

Git & GitHub — Version control and source code management.
